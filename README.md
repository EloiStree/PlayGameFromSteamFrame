# Play Game From Steam Frame

Let's play XInput game from Steam Frame

If you learn to code input simulation with XInput (Xbox), you can play 90-70% of the game in the world.

My aim is to teach code by playing game.

The day I bought the Steam Frame is the same day I learn that World of Warcraft: Forever is now playable from XInput natively 😁.

The equation for me is simple: 
- Teach how to play World of Warcraft Forever with Godot in XR with Steam Frame.

This guide is not specific to World of Warcraft.
It is for any game that support XInput
- 10 Seconds Ninja is good to start
- AmaZoo is good to train on chaining the level
- ARCS Raider and World of Warcraft are my trainig ground
